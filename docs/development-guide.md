# 独立开发版与窗口交互

当前源码支持隐藏任务栏按钮并保留托盘、四边吸附、30%–200% 缩放及鼠标穿透。拖动接近当前显示器工作区边缘 12 DIP 时吸附；缩放和切换完整/迷你模式保持已经吸附的边。右键菜单可调整这些选项，Ctrl+滚轮可缩放。

完整模式会根据当前工作区、DPI和已启用组件自动选取不超过用户偏好的可容纳整数比例。开启FPS后，新增卡片也参与适配；例如1320 DIP高的完整面板在168 DPI、1516像素高的工作区中，将70%偏好临时适配到65%。保存的70%不变，组件减少或工作区变大后恢复。迷你模式与任务栏保持原比例；极小工作区低于30%下限时仍使用滚动。回归检查覆盖全12卡的合成FPS渲染、底部卡片、适配后的命中、原吸附边和偏好恢复，不代表真实FPS采集或所有传感器已验收。

开启穿透后，单击托盘图标保留穿透，双击显隐；通过设置中的临时调整位置移动窗口。托盘不可用时不能开启穿透；收到 Shell 重建通知时先恢复直接操作，再重新注册图标。

菜单中的“鼠标穿透”开关会保存到 `Window/click_through`，下次启动在托盘初始化成功后自动恢复。要永久关闭，在设置中关闭穿透开关。托盘不可用或任务栏嵌入模式下保持可操作，仍保留已保存的偏好。

## 开发版隔离

### 普通 CI 产物的便携模式

在独立目录解压 CI 的 `Pulse.exe`，并在它旁边创建空文件 `pulse-portable.ini`。程序使用该目录的 `data/settings.ini` 和 `data/pulse_net.log`，窗口名称为 `Pulse Portable`；不读取安装版配置。没有标记文件时保留原有行为。便携目录及配置不能通过目录联接或符号链接指向其他位置；初始化失败时退出，不回落到安装版配置。

便携模式与安装版、开发版使用不同的单实例标识，可以共存；同一用户会话同时只运行一个便携实例。便携模式禁用自启、创建系统快捷方式和管理员重启，避免覆盖安装版入口。关闭并移走独立目录即可停止使用，不需要卸载。

`PULSE_DEVELOPMENT` 编译分支使用独立窗口名、单实例标识及配置目录。开发配置只能位于当前源码树登记的 `dev-work/sessions/<ID>/profile`；不会回落到安装版配置。开发版禁用自启、快捷方式、提权、任务栏嵌入、FPS 采集、网络探测与声音。

人工试用的固定默认值位于 [development-defaults.ini](../tools/development-defaults.ini)：完整模式、全部可用项目、70% 缩放、右侧吸附、不置顶、开启穿透。每次人工启动创建独立配置并应用这套预设；试用中的临时调整不会自动修改固定预设。70% 针对当前试用屏幕选择，其他屏幕的可见范围由工作区和 DPI 决定。

## 受保护的本地入口

### 开发与发布流程

容量接近上限时，先运行 `Pulse-Dev.ps1 -Action Artifact-Status`。它只读账本，显示各目录已登记字节、文件数、剩余字节和 85% 占用提示，不创建会话、不申请测试槽，也不把文件数冒充包含子目录的容量项数。`liveContentVerified:false` 表示这些是登记值，未重新核对磁盘内容。

需要核对可回收材料时运行 `-Action Artifact-Review`。它沿用容量租约、排他锁、完整身份检查及开发进程静止检查，在 `dev-work/evidence` 保存带哈希的精确清单。保留最近两份完整开发/正式构建作为最低保护，并额外保留最新验收动作、所有发布准备/包/回滚引用、其 Trial 及验收依赖。失败保留最新检查点；收尾不明材料全部保留。较早构建或会话中未被这些关系引用的 EXE、对象文件及截图可退役；配置、标记、回执、构建清单及未知对象保留。

`Artifact-Review` 本身只做复核。`Artifact-Retire -RecoveryInput` 接受 `reviewPath`、`reviewSha256`、`expectedFiles`、`expectedBytes` 和 `authorization`，将精确清单与当前引用重新核对后删除。开启 `local-artifact-policy.json` 中的授权保留策略后，Test/Test-Continue/Trial-Test 或发布校验成功、外层账本完成时自动退役不再需要的已登记产物，无需逐次确认；不运行定时清理，不在失败或中断时清理。

删除沿用同一项目锁及 Job/共享槽/CPU/时间/输出/容量保护。先锁定全部目标和祖先目录、核对文件标识与哈希，全部通过后才逐文件持久化删除意图并通过同一原生句柄删除。占用或漂移时拒绝整个批次；部分失败保留精确日志并阻止自动重放。账本保留退役身份，后续不会复用已退役的旧构建。清单不允许递归扩大目录范围；普通日志的 7 天/100 MiB 规则不适用于验收与恢复证据。本地容量、删除和恢复报告不随发布包上传。

`Workflow-Test` 使用原入口的 Job、共享槽、内存及容量保护，运行合成发布服务和实际 helper 检查；不会启动产品、编译器或真实发布请求。工具故障只补工具检查，已通过且身份一致的产品证据继续复用。

`Build` 和 `Release` 按编译输入、worker 兼容身份和编译配方复用同类已验收构建。`Release-Package` 复用完整验收包并自动调用 `Release-Prepare`，从原包清单和 Trial 回执生成 `publication-plan.json`，绑定附件哈希、发布说明及回退版本。该文件是本地维护记录，不属于上传附件。

新的源码交付通过 `Release-Source` 输入准确 `base`、`branch`、`tag` 和有界公开文件 `paths`；拒绝本机配置、维护证据和其他私有路径。入口核对 main 基线、逐文件远端 Git blob 及最终树，保存源码回执；未变化文件沿用基线。新的本地打包通过 `Release-Package` 输入 `tag`、`commit`、`artifactExe` 和 `trialReceipt`，从源码回执、正式构建清单与独立 Trial 绑定同一 EXE，不再为每版增加硬编码提交或构建目录。源码、构建或试运行身份变化时拒绝打包。

`Release-Publish` 输入必须包含 `tag`、`expectedPlanSha256` 和 `authorization: {repository, tag, commit, publish:true}`，且有当前发布授权。它使用官方 gh 核验账号和仓库权限，先持久化操作意图，再创建草稿、上传或公开。草稿按 ID 读取；同名附件必须匹配大小和 SHA256，禁止覆盖。丢失响应时先核对远端，已确认成功才继续，未确认结果拒绝盲目重试。公开前核对标签；成功后接 `Release-Verify`。

`Release-Verify` 可复用身份一致的历史公开下载证据，明确标记并非本次联网验证。`Release-Status` 只报告已记录状态，不代表实时输入或远端状态。旧源码发布与 CI 导入的精确准入仍保留，不接受任意提交绕过绑定。

入口使用仓库内的 `tools/shared/pulse_artifact_storage_v3.cjs`，核验固定 SHA256 后加载；它在原共享 v2 上增加精确受管文件退役、零删除拒绝收尾和退役身份记录。原 v2 源码、共享安装及其他项目不变。默认数量限制仍为 512，只有明确配置并登记的目录允许 1024；字节、身份、排他锁和回退保护独立保留。Job、共享槽和内存策略模块仍由本机受验证的环境提供；仓库不包含个人环境配置或旧验收材料。历史上游合并辅助入口依赖本机维护配置，不作为新安装环境的通用入口。

工具合成检查已覆盖中断续办、重复操作拒绝、输入/远端漂移、权限和标签冲突、Unicode 参数以及资源上限拒绝；新自动发布器尚未用于真实 GitHub 发布。实际收益留待下一次授权交付观察，不能将工具检查耗时视为整次交付提速比例。

```powershell
.\tools\Pulse-Dev.ps1 -Action Build
.\tools\Pulse-Dev.ps1 -Action Test
.\tools\Pulse-Dev.ps1 -Action Debug
.\tools\Pulse-Dev.ps1 -Action Run -Interactive
```

这是依赖本机共享资源保护设施的开发入口，不是通用安装程序。运行前需要由维护者提供已验证的 `tools/dev-environment.local.json`，包括 Node、Python、LLVM-MinGW/LLDB、安装版只读对照路径、容量/Job/内存策略/共享槽模块路径及工具 SHA256。该文件不随仓库分发；缺失或身份漂移时应停止，不应直接执行 worker 或候选程序绕过保护。Python 渲染检查另使用 Pillow。

入口遵循 [local-artifact-policy.json](../local-artifact-policy.json)，在生成前取得容量租约；默认 daily 内存档位。构建使用受限 Job 和进程树，生成开发 GUI、后端及普通分支兼容检查程序。编译输入与已接受的本地编译证据完全一致时允许复用；没有旧证据时走新构建，不下载或假造验收材料。

`Test` 和 `Debug` 使用私有 Windows desktop，不切换输入桌面或注入真实键鼠；托盘注册检查使用独立合成协议宿主。`Run -Interactive` 仅供用户明确要求的人工试用，最长 30 分钟，关闭后完成资源回收及安装版对照。它在可见窗口和托盘就绪后应用右侧吸附与穿透，并留下启动回执。

本机路径、验收回执、会话配置、截图、编译产物和内部工作记录均留在 Git 忽略目录中。

## 已验证范围

- 开发版与普通分支编译链接；LLDB 断点、单步、继续运行和正常退出。
- 私有桌面窗口样式、吸附/脱离、缩放边界及模式锚点、跨进程穿透命中、托盘回调恢复、设置重读。
- 完整/迷你界面 30%、100%、200% 的实际 Direct2D 渲染目标图像；高 DPI 下 30% 迷你窗口尺寸修复。
- 用户授权的人工启动：固定预设自动恢复、正常退出、再次启动；安装版保护对象保持不变。

合成托盘检查不是 Explorer 托盘视觉验收，渲染目标图像不是桌面合成截图；尚未据此宣称真实跨屏拖动或发布安装包验收。提交源码不会安装、替换或自动更新现有 Pulse。
